$<: Represents the first prerequisite (dependency) of the rule.
$^: Represents all prerequisites (dependencies) of the rule $?: Outputs all prerequisites newer than the target $? And $^ and $< hey: one two # Outputs "hey", since this is the target name @echo $@ # Outputs the first prerequisite using $< (it will print "one") @echo "The first prerequisite is: $<" # Outputs all prerequisites newer than the target @echo $?
